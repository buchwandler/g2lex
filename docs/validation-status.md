# Current validation status

This page is the current validation-status location for the repository. The
historical 0.1.0 release-candidate record is retained at
[docs/validation/v0.1.0.md](validation/v0.1.0.md) and should not be read as the
status of later releases.

Release and CI status is established by the workflow checks: the supported
Python matrix, full tests, branch-aware coverage, package build and smoke tests,
and strict HTML and JSON documentation builds. Results should be updated with
the corresponding release record rather than copied from an older candidate.

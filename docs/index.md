# G2Lex

G2Lex compiles pronunciation dictionaries into deterministic, mmap-friendly binary
lexicons for exact Python lookup.

```{toctree}
:maxdepth: 2

changelog
```

## Quick start

Install the released package:

```bash
python -m pip install g2lex
```

See the repository [README](https://github.com/buchwandler/g2lex#readme) for
installation, source adapters, the stable G2Lex Binary Lexicon v1 format, and
Python API examples.
